# Original blender2ogre images

The README uses the original screenshots and feature examples from OGRECave/blender2ogre, preserved under `images/` with the upstream source and credits. Its sections cover mesh triangulation, merge offsets, external materials, vertex groups, custom normals, skeletal/shape animation, particles, vertex colors, skyboxes and mesh previewing.

Source: [OGRECave/blender2ogre](https://github.com/OGRECave/blender2ogre), pinned baseline `0d094a40a589752802a9f8823cf08cd8acd6f8fe`. The original README sections and author credits are retained in the main README, with current compatibility/install guidance and our fixes identified separately.
