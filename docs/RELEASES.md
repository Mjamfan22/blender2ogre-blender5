Download `blender2ogre_Blender_5_2_v<version>.zip` to install the add-on. The source and documentation archives are separate reference downloads. Each `PATCH_NOTES_v<version>.md` covers that version's changes, installation, verification and limits; each `DOCUMENTATION_v<version>.zip` contains a `GETTING_STARTED.md` and `RELEASE.md` alongside the matching historical guides. [Installation and upgrade instructions](INSTALLATION.md) explain how to upgrade safely.

The eight releases were published in ascending version order. The four oldest installers were recovered byte for byte from their preserved verified installations: their hashes and sizes match the original records. Their source tags are clearly identified archival reconstructions made at publication time from those exact runtimes and the original upstream baseline. Versions 0.9.8–0.9.11 point to their existing development commits. Commit dates on archival reconstructions record publication work, not backdated development.

The check counts are the preserved results for each exact historically installed ZIP, with zero failures or skips. Publication separately verifies every installer hash, source/runtime file equality, archive integrity and complete-patch reconstruction. Tests that require private asset fixtures cannot all be reproduced from a public checkout; the current clean-checkout subset and full-run limits are described in [validation](VALIDATION.md). Historical source documentation retains its original preparation state, including earlier draft-release wording; the accompanying release guide records the public download instructions.

These are independent adaptation releases. Original blender2ogre sections, images, credits, LGPL licensing and bundled-tool notices are preserved. Windows x64, Blender 5.2.3 LTS and classic OGRE are the verified scope; [remaining limitations](ROADMAP.md) still apply.
