## Import measurement

The v0.9.6 baseline took **39.019 seconds**. The earlier v0.9.7 confirmation in a fresh Blender process took **7.706 seconds** (5.06× faster). A source run took 7.872 seconds. The metadata-only v0.9.8 release retained the same implementation and took **6.703 seconds during the full installed-payload suite**. These runs have different process/cache histories; the latter number is not an additional speed improvement claim.

The timer covers the import operator, including native conversion, XML parsing, mesh construction and material loading. Startup, snapshot writing and interactive redraw are excluded. Operating-system caches were not flushed. Timings vary across assets and machines.

All **190,826 triangles**, **8 UV layers**, custom normals and **3 image-backed materials** were retained, with no import warnings. Every triangle corner was compared against the previous-release snapshot, with maximum observed differences of zero for positions, normals, UVs and material assignments. Shared geometry now uses **121,422 vertices**, replacing 364,266 duplicated vertices; triangles were not decimated and distinct source vertices were not welded.

The private model pack and numerical corner snapshots are retained locally and are not redistributed in this repository. Sanitized [baseline](../docs/validation/import_benchmark_baseline.json), [current run](../docs/validation/import_benchmark_optimized.json) and [equivalence results](../docs/validation/import_speedup.json) are included.

## Reproduction and boundaries

The included **65-check self-contained subset** builds its own synthetic fixtures and can run from a clean Windows checkout using Blender 5.2.3. Eight further checks require OGRE sample models, two upstream reporter .blend files, the private resource pack or baseline corner snapshots. See [contributing](../CONTRIBUTING.md) and [fixture provenance](../tests/fixtures/README.md). Skips are reported explicitly; a 65-check run is not represented as a full 73-check run.

GitHub CI performs Python syntax checks, per-file package hashes, deterministic ZIP validation and documentation-link checks. It does not run native Blender regression or game-engine rendering tests. No verified claim is made for Linux, full OgreNext rendering or arbitrary custom engine shader programs.
